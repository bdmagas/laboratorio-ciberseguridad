# laboratorio-ciberseguridad

# Mi primer laboratorio de ciberseguridad

Trabajo práctico del curso de Ciberseguridad de Coderhouse.

## Objetivo

Crear una máquina virtual con Windows 11 y aplicar algunas configuraciones básicas de seguridad para utilizarla como entorno de prácticas.

## Configuración realizada

- Instalación de Windows 11 en VirtualBox.
- Configuración de red en modo NAT.
- Creación de un usuario estándar (`labuser`).
- Actualización del sistema mediante Windows Update.
- Verificación de que SMB 1.0 esté deshabilitado.
- Creación de snapshots para poder recuperar la máquina virtual.

## Reporte técnico

El PDF incluido en este repositorio contiene las capturas de pantalla y una breve explicación de cada configuración realizada.
